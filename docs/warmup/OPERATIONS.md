# Warm-up operations

Use the existing Gmail, Microsoft Graph or SMTP/IMAP mailbox connection. Run **Domain health** first and resolve missing SPF, DKIM or DMARC evidence. Start and resume verify connectivity and refuse held or unhealthy mailboxes. Use pause, resume and stop from the program page. Starting again after a stopped or completed program requires fresh enrollment and confirmation.

The BullMQ scheduler examines due active programs. Quota reservations share the workspace campaign send lock and consume capacity for mailbox, workspace, and domain limits. Genuine reviewed messages are submitted with the existing adapter. The app checks suspension, emergency pause, domain health, authorization and suppression. Control actions cannot recall a submission already underway.

Review ambiguous attempts in the program activity view. Empty Sent evidence leaves the attempt ambiguous. Positive sync evidence can update acceptance while the review is open. An operator review records reason and evidence and provides no resend action. If a worker stops after reserving an attempt, stale reservations become uncertain. Pause and investigate before resuming.

Take and validate a backup before deploying the additive migration. Rehearse rollback by restoring to a separate disposable database. Validate the migration ledger, warm-up tables and existing campaign records before restarting workers.
