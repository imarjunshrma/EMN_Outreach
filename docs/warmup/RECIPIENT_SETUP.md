# Authorized warm-up recipients

Authorize only owned test inboxes and participants who explicitly agreed to the controlled messages. Paste individual addresses or a comma/newline-separated list on the program screen. Supply a redacted consent reference and an individual daily limit. The program stores the authorizing administrator and timestamp. Address validation checks syntax. The administrator verifies account ownership or consent outside the app.

Use **Withdraw** if permission changes. The system retains historical activity and excludes withdrawn recipients from future submissions. It rechecks workspace suppression and prospect status before submission. Prospect lists and scraped addresses are unsuitable.
