## Detailed source index

API endpoint registry is in `API_REVIEW.md`; all page files are in `FRONTEND_REVIEW.md`. Route schemas and roles are declared in `backend/src/routes/*.ts` and centrally enforced in `backend/src/http/router.ts`.

## Status interpretation

- **COMPLETE**: implementation plus adequate internal verification actually executed for intended behavior.
- **PARTIAL**: source and some tests exist, but current verification is incomplete or behavior has known gaps.
- **BLOCKED**: local service/capability prevented execution.
- **REQUIRES CREDENTIALS**: real service check cannot be simulated as live behavior.

No major product area is marked COMPLETE by this audit because DB/Redis-backed suites could not run in this environment.
