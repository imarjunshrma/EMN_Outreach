# AI training guide

Open **AI Outreach Brain → Training** in a workspace. Add concise rules with the correct category and priority; conditional rules require a condition. Trigger terms are deterministic blocks for AVOID/MANDATORY priorities. Rule conflicts are warnings that need human review.

Add positive examples to show preferred style and negative examples to show what to avoid. Use only content you are authorized to store. Examples are text-only, tenant-scoped, selected by simple word overlap, and included as untrusted data. Avoid prospect personal data and secrets.

When editing a draft, explain the change if useful. Keep scope at Campaign for local preferences. Mark Global only when the preference should apply to future campaigns in this workspace. Suggestions require repeated heuristic patterns and never change prompts until an admin explicitly accepts them. Review generated content and evidence before approval; this feature does not replace human review or the existing send approval gates.
