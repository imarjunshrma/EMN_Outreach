## Shared frontend behavior

- API client uses relative same-origin `/api/v1` URLs, cookies, and CSRF header for unsafe verbs (`frontend/lib/api.ts`).
- Hooks and invalidation live in `frontend/lib/hooks.ts`; app shell/navigation is under `frontend/components/shell/`.
- File inventory does not establish that all controls are wired or that mutations persist. Every page needs browser review with real API and isolated DB.
