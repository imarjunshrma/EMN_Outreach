## Contract and enforcement

- `backend/src/http/router.ts::mountRoutes()` validates defined Zod body/query schemas, rate limits, authentication, workspace membership, role, MFA policy, API key scope, and standard JSON responses. Raw responses are intentionally route-defined.
- Auth failures use `backend/src/http/middleware.ts` and common error handling in `backend/src/http/router.ts` / `backend/src/app.ts`.
- The route source is the definitive contract. `API_DOCUMENTATION.md` and generated OpenAPI should be regenerated after API contract changes.
- Matrix has no independent proof for every service transaction, error branch, record scope, or response shape. Those require API tests with PostgreSQL/Redis; current `npm test` setup is blocked by missing local PostgreSQL.
